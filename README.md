# ADM — L’Académie des Mots

Jeu de découverte et de reconstitution de citations, proverbes et maximes.

- [Prototype alpha](https://tigreoslam23.github.io/ADM-Academie-des-Mots/) : six missions du chapitre I.
- [Atelier Mots en désordre 0.3](https://tigreoslam23.github.io/ADM-Academie-des-Mots/adm-v03.html) : page de test séparée avec profils, formats Express/Classique/Marathon/Infini, score, pause et reprise.

L’atelier utilise les 18 textes du prototype pour éprouver les mécaniques. Les références et anecdotes doivent être vérifiées avant de constituer la banque de 300 entrées. Le barème numérique est provisoire ; Carnet, Mémoire, grades et parcours débloquables restent à développer.

La sauvegarde est locale à chaque navigateur/appareil. Le profil de démonstration ne se synchronise pas entre appareils.
